# LeadVerify handover package

Start with `leadverify-antigravity-handover.md` and follow it.

## Contents
- `leadverify-antigravity-handover.md`: the build brief (scope, workflow, stack, database, security, screens, questions).
- `design/`: the source for all 14 screens (`*.dc.html`) and `canvas.json` (screen sizes and positions).
  Read the markup for exact colours, sizes, spacing and copy. Photos in these files appear as `/_blob/<id>` references that will not resolve outside the design tool; use `photos/` instead.
- `photos/`: the 10 website and Talent Network photos, already resized for web. The brief maps each file to its slot and crop.
- Also give Antigravity the exported `LeadVerify_Brand_Identity_Pack.html` as a visual reference. Open it in a browser to see every screen rendered.

## Screen files
Main = Logo, Colour, Type (typography and voice), Applications, Website, Talent (landing), Apply (step 1), Apply2 to Apply5 (steps 2 to 5), Consent (step 6, mobile), Confirmation, Admin.

Photos are AI-generated. Do not present them as real people.
